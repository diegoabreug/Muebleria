# Mueblería Solano: Product Catalog

A responsive online catalog for **Mueblería Solano**, a furniture store. It's a single-page site built with plain HTML, CSS and JavaScript, with no frameworks and no build step.

**Live site:** https://diegoabreug.github.io/Muebleria/

## Features

- Product grid rendered from a JavaScript data array
- **Category filters** and **live search** as you type
- **Product detail modal** (closes with the Escape key)
- Responsive layout with CSS Grid and media queries

## Tech stack

HTML5 · CSS3 (Grid) · Vanilla JavaScript · GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
